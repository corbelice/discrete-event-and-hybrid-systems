
# Discrete-Event and Hybrid Systems

**TU Dresden | Summer Semester 2026**  
**Ereignisdiskrete Systeme 2 (EDS2)**

## Overview

This repository presents selected academic exercises and modeling work completed during my Erasmus year at Technische Universität Dresden.

The coursework explored the modeling, analysis and control of discrete-event and hybrid systems, combining mathematical methods with engineering applications.

## 1. Hybrid Systems

**Topics:** Hybrid Automata, Continuous and Discrete Dynamics

Study of systems combining continuous evolution with discrete transitions.

Key concepts:
- Hybrid system modeling
- Operating modes and state transitions
- Switching conditions
- Interaction between continuous dynamics and discrete events

## 2. Motion Control

**Topics:** Trajectory Planning, Sequential Control

Study of motion profiles and their representation through sequential control logic.

Key concepts:
- Acceleration and deceleration phases
- Velocity profiles
- Trajectory generation
- State-based motion sequences
- Modeling concepts associated with MATLAB/Simulink and Stateflow

## 3. Max-Plus Systems

**Topics:** Discrete-Event Systems, Petri Nets, Max-Plus Algebra

Mathematical analysis of event-driven systems and their temporal behavior.

Key concepts:
- Timed Petri nets
- Max-Plus algebra
- Event synchronization
- Cyclic behavior and system timing

## Technical Skills

- Discrete-event system modeling
- Hybrid systems
- Finite state machines
- Motion control
- Mathematical system analysis
- MATLAB / Simulink / Stateflow concepts
